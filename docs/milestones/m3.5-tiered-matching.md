# Milestone 3.5: Match on job insert

**Status:** In progress  
**Product change:** Bulk analyze removed — each job gets a **full match analysis** when saved.

## New flow

```
Resume (profile) → Paste job → Extract fields → Save & analyze
                                                    ↓
                              POST /jobs { profile_id, ... }
                                                    ↓
                              MatchAnalysis queued (full depth)
                                                    ↓
                              Job detail + home pipeline show score
```

## Rationale

- User always has a profile before adding jobs
- Match is the reason they paste a job — run it immediately
- Eliminates "Analyze all" bulk step and cascade complexity in the UI
- One full `match_analysis` call per job (acceptable at intake volume)

## API

`POST /api/v1/jobs`

```json
{
  "title": "...",
  "company": "...",
  "description": "...",
  "profile_id": "uuid",
  "raw_metadata": { "match_summary": "...", "requirements": [] }
}
```

Response includes `match_analysis_id` when match was queued.

## Removed from product

- `POST /match-analyses/batch` (bulk analyze)
- Home page "Analyze all / Re-analyze all" buttons

## Kept
